The Mechanism

How SafePost Works

SafePost separates scheduling from publishing. The schedule lives on the server; the actual posting happens locally in your own browser, using your own session.

1

Create jobs in the dashboard

Write your post, pick the target groups, and choose a time. The job is saved to the server and appears in your queue.

The extension picks them up

The Chrome service worker stays in touch with the server. When a scheduled time arrives, it receives that job.

3

Publishes from your session

The extension posts to facebook.com as the account already signed in to your browser. SafePost never sees or stores your Facebook password.

Built into the dashboard

AI Post Assistant

Not sure what to write? Describe your topic and the assistant drafts variations for you — then shortens, expands, adds emoji, or changes tone on request.

Example
Write a post about a new pizzeria opening downtown
Friendly

🍕 Big news for pizza lovers! A brand-new pizzeria just opened downtown — wood-fired, fresh dough daily, and the smell alone is worth the walk. Who’s coming with me?

Professional

A new wood-fired pizzeria has opened in the city centre, serving dough made fresh each morning. Now open for lunch and dinner — reservations recommended for weekends.

Short & punchy

New pizzeria downtown. Wood-fired. Fresh dough daily. 🔥 Go before the queue finds out.

The assistant runs inside the dashboard, where your API usage stays behind your own account.

Modern stack.
Reliable by design.

Three separate pieces, each doing one job — a responsive dashboard, a realtime server, and a local browser extension.

React Dashboard

Responsive web app for writing, scheduling, and tracking every post.

Realtime Server

Node.js backend with realtime sync, so the queue updates the moment anything changes.

Chrome Extension

A background worker that does the actual posting locally, from your own session.

Extension setup

  1. 1
    Open chrome://extensions in Chrome.
  2. 2
    Turn on Developer mode (top right).
  3. 3
    Click Load unpacked and select the safe_post_extension/ folder.
  4. 4
    Open the extension popup and run the connection test.
